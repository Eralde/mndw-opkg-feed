mndw OPKG feed

Install the hosted feed bootstrap:

curl -fsSL https://eralde.github.io/mndw-opkg-feed/add_repo.sh | sh

Manual feed paths:

  • /aarch64-3.10
  • /mips-3.4
  • /mipsel-3.4

The feed publishes signed indexes and a public key for future opt-in. Device-wide check_signature remains disabled so existing configured feeds are not disrupted.
